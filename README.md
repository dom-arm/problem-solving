# Vad finns i detta repository?

Här finns mina lösningar på programmeringsproblem från [open.kattis.com](https://open.kattis.com).

Jag dokumenterar i första hand problemlösning här. Jag visar hur jag tänker och resonerar mig fram till lösningar.

Jag börjar alltid med att noggrant reda ut och förstå problemet. För mig hjälper det att med egna ord skriftligen upprepa/analysera problemet.

Jag övar även algoritmer och datastrukturer med dessa problem.

**Att notera:**

* Alla lösningar är skrivna i Java ([open.kattis.com](https://open.kattis.com) använder Java 21)
* Det finns bara markdown-filer i detta repo (koden finns inbäddad)
* Om jag inte är färdig med ett problem finns det under mappen `ongoing/`
* AI används **inte** i detta repo
